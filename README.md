# Interpol Most Wanted - Android App 🚨

Una aplicación Android desarrollada en Kotlin que consulta la API de Interpol para mostrar información sobre los criminales más buscados a nivel internacional.

## 📋 Descripción

Esta aplicación consume la API oficial de Interpol (Red Notices) para obtener y mostrar en tiempo real información sobre personas buscadas internacionalmente. Presenta los datos en una interfaz moderna y fácil de usar desarrollada con Jetpack Compose y Material Design 3.

## ✨ Características Principales

- **Consulta en Tiempo Real**: Obtiene datos actualizados de la API de Interpol
- **Búsqueda Avanzada**: Filtra criminales por nombre o ID de entidad
- **Información Detallada**: Visualiza datos completos de cada persona buscada
- **Interfaz Intuitiva**: Diseño Material Design 3 con navegación fluida
- **Manejo de Estados**: Indicadores de carga, errores y estados vacíos

## 🛠️ Tecnologías Utilizadas

- **Lenguaje**: Kotlin
- **UI**: Jetpack Compose + Material Design 3
- **Arquitectura**: MVVM (Model-View-ViewModel)
- **Networking**: Retrofit 2 + Gson
- **Asincronía**: Kotlin Coroutines
- **API**: Interpol Red Notices API

## 🚀 Funcionalidades

- Lista completa de criminales buscados por Interpol
- Búsqueda instantánea por nombre o ID
- Detalles individuales de cada persona buscada
- Avatares generados dinámicamente con iniciales
- Contador de resultados en tiempo real

## 💻 Instalación

1. Clona el repositorio:
```bash
git clone https://github.com/tu-usuario/interpol-most-wanted.git
```

2. Abre el proyecto en Android Studio

3. Sincroniza las dependencias de Gradle

4. Ejecuta la aplicación

## 🔧 Requisitos

- Android Studio Hedgehog o superior
- MinSDK: 24 (Android 7.0)
- Conexión a Internet
